# VTuber Companion 앱 기획서

## 1. 프로젝트 개요

Android에서 먼저 개발하는 대화형 Live2D 캐릭터 앱이다.

앱을 실행하면 로딩 화면 뒤에 캐릭터가 나타나며 사용자의 터치와 음성에 반응한다. 이후 OpenAI 기반 대화, 현실 시간에 따른 생활 상태, 토큰형 과금 모델을 단계적으로 추가한다.

핵심 개발 원칙은 모든 기능을 한 번에 만들지 않고, 캐릭터와 실제로 대화하는 경험이 재미있는지 빠르게 검증하는 것이다.

## 2. 현재 구현된 MVP

- Android 앱 패키징 및 Galaxy 기기 설치
- 앱 시작 로딩 화면
- Live2D 상반신 캐릭터 표시
- 선택 모델: Pachan
- 드래그에 따른 얼굴·눈·몸 움직임
- 화면 터치 및 인사 인식 시 고개 반응
- 자동 호흡과 눈 깜빡임
- 일본어 음성 인식
- `こんにちは`, `こんにちわ`, `今日は` 등 인사 인식
- VOICEVOX 기반 일본어 캐릭터 음성
- VOICEVOX 실패 시 기기 TTS 사용
- 반복 음성 인식 세션 충돌 방지

현재 모델에는 제작자가 제공한 별도 표정 및 터치 모션 파일이 없다. 따라서 터치 반응은 파라미터 기반 고개 움직임으로 구현되어 있다.

## 3. 사용자 경험 흐름

1. 사용자가 앱을 실행한다.
2. Live2D Core, 모델, 텍스처, 물리효과를 불러오는 동안 로딩 화면을 표시한다.
3. 모델 준비가 끝나면 캐릭터와 음성 버튼을 활성화한다.
4. 사용자가 캐릭터를 터치하거나 드래그하면 캐릭터가 반응한다.
5. 사용자가 말하기 버튼을 누르고 일본어로 인사한다.
6. 음성 인식 세션이 완전히 종료된 뒤 캐릭터가 움직이고 일본어 음성으로 답한다.

## 4. 단계별 개발 계획

### 1단계: 기술 검증

- Live2D 모델 로딩
- 터치·드래그 반응
- Android WebView 성능 확인
- 실제 기기 설치와 마이크 권한 확인

상태: 완료

### 2단계: 음성 인사 MVP

- 일본어 음성 인식
- 인사 문장 판별
- 캐릭터 반응
- 무료 TTS 연결
- 반복 실행 안정화

상태: 완료

### 3단계: 자유 대화

- 사용자의 전체 발화를 텍스트로 변환
- 자체 백엔드로 발화 전송
- OpenAI API로 답변 생성
- 답변을 TTS로 재생
- 대화 중 캐릭터 표정 및 립싱크 적용
- 대화 내역과 캐릭터 기억 범위 정의

OpenAI API 키는 앱에 포함하지 않는다. 키는 반드시 서버에서 보관한다.

### 4단계: 캐릭터 상태와 현실 시간

- 기기 시간 또는 검증된 서버 시간 사용
- 아침·낮·저녁·수면 상태
- 앱 재실행 시 경과 시간으로 상태 복원
- 수면 중 터치하면 졸린 표정이나 짜증 반응
- 사용자와의 친밀도 및 최근 대화 상태 반영

기기 시계 변경에 의한 조작을 막아야 한다면 서버 시간을 사용한다.

### 5단계: 토큰 BM과 계정

- 사용자 인증
- 서버에 토큰 잔액 저장
- 대화 요청 전에 잔액 확인
- 실제 사용량 기준 토큰 차감
- 중복 결제 및 중복 차감 방지
- 구매 복원과 거래 영수증 검증

권장 백엔드는 FastAPI 또는 Node.js이며 데이터베이스는 PostgreSQL을 기본 후보로 한다.

### 6단계: 출시 준비

- 오리지널 캐릭터 제작 또는 정식 라이선스 구매
- 개인정보 처리방침과 마이크 사용 안내
- 장애 및 비용 모니터링
- Android 앱 서명과 Play Console 설정
- 결제 정책 검토
- 저사양 Android 기기 최적화
- 이후 iOS 프로젝트 추가

## 5. 권장 시스템 구조

### Android 앱

- Capacitor 네이티브 컨테이너
- TypeScript UI 및 상태 관리
- Live2D Cubism SDK for Web
- Capacitor 음성 인식 플러그인
- VOICEVOX 또는 상용 TTS

### 백엔드

- 로그인 및 사용자 식별
- OpenAI API 프록시
- 시스템 프롬프트 및 캐릭터 설정 관리
- 토큰 잔액과 사용 내역 관리
- 대화 기록 및 장기 기억 관리
- 악용 방지와 요청 속도 제한

### 외부 서비스

- OpenAI: 대화 생성
- TTS 서비스: 음성 합성
- 앱 스토어 결제: 토큰 구매
- 모니터링 서비스: 오류 및 비용 추적

## 7. 보안 및 비용 원칙

- OpenAI API 키와 서버 비밀값을 APK에 넣지 않는다.
- 클라이언트가 보낸 토큰 잔액을 신뢰하지 않는다.
- 결제 결과는 서버에서 스토어 영수증으로 검증한다.
- 동일 요청이 재전송되어도 한 번만 차감되도록 멱등성을 적용한다.
- 사용자별 요청 빈도와 일일 한도를 둔다.
- 긴 대화는 요약하여 모델 입력 비용을 제한한다.
- 로그에 음성 원문이나 개인정보를 불필요하게 저장하지 않는다.

## 8. 모델 및 라이선스

현재 Pachan 모델은 개인 사용 목적으로 내려받은 무료 모델이다.

- 원본 배포 페이지: https://booth.pm/en/items/4711410
- 원작자와 리거 크레딧 요구 조건 확인 필요
- 모델 파일의 재판매, 재배포 및 자작 주장 금지
- 앱을 제3자에게 배포하기 전 별도 허가 범위를 다시 확인

서비스 출시 전에는 오리지널 모델 또는 앱 포함 배포가 명시적으로 허용된 모델로 교체하는 것이 안전하다.
